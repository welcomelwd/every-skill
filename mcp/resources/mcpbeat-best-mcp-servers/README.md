Every MCP server in the official registry, ranked by **measured uptime and real
installs** — not by stars, not by hand.

This list is rebuilt every night from live checks. Every remote endpoint gets a real
JSON-RPC handshake every 15 minutes; install counts come from npm and PyPI. Nothing
here is curated manually, which is why nothing here goes stale.

## Why another list

There are four hand-curated lists of MCP servers. We checked the largest one against
our own probes: of the entries we could match, **144 point at repositories that no
longer exist**, 61 servers never answer, 7 were archived by their authors. That is
what happens to a list edited by pull request — a line goes in once and nobody opens
it again.

This one has no maintainer to forget. It is generated from the same measurements that
run the site, so a server that died last night is marked tonight.

## How the numbers are made

- **Liveness** — a real MCP `initialize` handshake to every remote address, every
  15 minutes. 8 079 816 checks so far. A refusal with an auth challenge counts as alive:
  the server runs, it just wants a key.
- **Installs** — weekly downloads from npm and PyPI. Stars measure how many people
  liked a link; downloads measure how many run the thing.
- **Tools** — read from each server with `tools/list`, stored with the date.
- **Nothing is hand-picked.** No submissions, no sponsorships, no ordering by favour.
