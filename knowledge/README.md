# Knowledge

Knowledge 目录用于保存可检索、可引用、可验证的领域知识。

## 子类

- [security](security/README.md)：CVE、漏洞、补丁、PoC、情报和安全机制。
- [reverse-engineering](reverse-engineering/README.md)：二进制、固件、文件系统、反汇编和仿真。
- [protocols](protocols/README.md)：协议、报文、状态机、认证和兼容性。
- [products](products/README.md)：产品、版本、组件、架构和部署形态。
- [tools](tools/README.md)：工具能力、参数、版本、平台和限制。
- [standards](standards/README.md)：标准、规范、指南和最佳实践。
- [cases](cases/README.md)：分析过程、实验记录、验证结果和复盘。
- [datasets](datasets/README.md)：数据集、样例、字段、许可和质量说明。
- [glossary](glossary/README.md)：术语、缩写、别名和概念关系。
- [_template](_template/README.md)：新建 Knowledge 条目的模板。

## 知识条目要求

每条正式知识至少说明标题、类型、来源、版本或日期、更新时间、可信度、敏感级别和相关条目。事实、推断和待验证假设必须分开。
