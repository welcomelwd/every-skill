# GitHub AI 热门资料

本目录用于保存按日筛选的 GitHub AI 项目、Skill、MCP、Agent、模型与训练工具、数据集、评测资料及 AI 安全相关资源。

## 收录原则

- 优先检查 GitHub Trending、GitHub 仓库页面、README、Release 和项目文档。
- 重点关注 AI、LLM、Agent、MCP、RAG、推理、训练、评测、开发工具和 AI 安全。
- 每个条目记录项目链接、用途摘要、来源日期、活跃度或热门依据、分类和可信度。
- 按 canonical repository URL 去重；项目有重大更新时可以在新的日期摘要中再次记录。
- 只保存结构化摘要、分析笔记和外部链接，不复制第三方源代码、凭据或未经授权的数据。
- 对无法从公开来源确认的版本、许可证、指标和安全结论标记为“待确认”，不自行补全。

## 归档格式

- 每日文件：YYYY-MM-DD.md
- 记录字段：项目、仓库链接、主要分类、子分类、项目定位、入选理由、热门或活跃度依据、许可证（如可确认）、来源、可信度和待验证事项。
- 每次运行先读取已有摘要和目录，避免重复写入。
- 没有新增或显著更新项目时，不创建空提交。

## 分类规则

项目按主要用途进入以下路径：

- skill/：方法、步骤、评测流程和可复用执行规范。
- mcp/：MCP Server、Tool、Resource、Prompt、Client 和安全边界。
- agent/：角色、工作流、记忆、运行时、提示词和评估。
- knowledge/：项目事实、产品资料、工具说明、标准、案例和数据集。

如果已有子类不能准确表达项目用途，才新增小写连字符命名的子类，并同步添加该目录的 README.md 与 docs/TAXONOMY.md 说明。
