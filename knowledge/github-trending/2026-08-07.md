## 初步观察

1. Agent 项目的工程重点正在从单一 Prompt 扩展到工作流、Skill、记忆、沙箱、工具和消息接入的组合。
2. AI 平台与本地模型工具仍是高价值资料来源，但部署、许可证、模型权重和硬件兼容性需要单独验证。
3. 对网络安全和逆向分析场景，优先关注可隔离运行、工具权限、证据保留和结果可复现性。

## 待验证事项

- 各项目当前版本、最近 Release、模型兼容矩阵和部署资源需求。
- 许可证是否适合商业使用，以及第三方模型/数据集的附加许可。
- Agent 工具调用、沙箱、网络访问和外部写入的默认权限边界。
