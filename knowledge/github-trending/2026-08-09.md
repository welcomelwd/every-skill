## 本批次观察

1. 今日 Trending 的主线是可安装 Agent Skills 与长任务 Agent，Skill 正从提示说明升级为带 CI、质量门禁和多运行时适配的工程包。

4. AI 安全与评测工具需要同时记录模型参数、数据版本、提示模板和执行环境，才能形成可比较证据。
