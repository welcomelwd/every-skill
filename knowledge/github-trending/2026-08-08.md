## 1. anthropics/skills

- 主要用途：参考 skill 的目录组织、元数据、触发描述、说明文档和复杂文档处理技能。
- 入选理由：与本仓库的 `skill/` 结构直接对应，且 2026-08-07 有与 Managed Agents、GitHub skills 加载和预算控制相关的内容更新。

- 可信度：高，来自官方仓库 README、GitHub 页面和最近提交。
- 安全边界：不要把示例 skill 直接用于关键业务；执行脚本、网络访问、文件处理和第三方服务前应审查权限。不同子目录许可不同，复用前必须逐项确认。
- 事实：仓库包含 `skills/`、`spec/` 和 `template/`，并使用 `SKILL.md` 描述技能。

## 本批次观察

1. Skill 正从单一提示词转向“目录规范 + 脚本资源 + 触发描述 + 评测/验证”的可移植能力包。

4. Knowledge 项目适合做导航与案例索引；课程中的外链、Notebook、模型和数据许可仍需逐项核验。
