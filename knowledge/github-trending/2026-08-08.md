## 晚间批次观察

1. Skill 生态正在形成官方规则包与社区索引两条路线：前者强调可执行方法，后者强调发现与组合。
2. 浏览器和云 MCP 的价值很高，但也直接扩大了身份、网络、资源变更和费用风险面。
3. Agent 工作流的重点从单轮调用转向图编排、持久状态、恢复、并行与人工审批。
4. 课程型 Knowledge 项目适合建立主题导航和案例入口，运行示例前仍需独立核验依赖、数据和成本。

## 晚间需要人工关注

- github/awesome-copilot 的条目由社区贡献，安装任何 Agent、Skill、Hook、插件或 MCP 配置前应逐项审查。
- microsoft/playwright-mcp 与 awslabs/mcp 都能触发高影响外部动作，生产使用必须采用隔离环境和最小权限。
- google/adk-python 2.0 相对 1.x 有破坏性变化；已有项目迁移前需单独评估。
- 两个课程仓库只建立索引，不自动执行 Notebook、复制大段课程内容或下载模型与数据。
